10.在黑马点评基础上新增了通过AOP实现的限制刷接口、限制刷验证码、验证码用一次就作废、退出后旧登录凭证失效。
| 功能 | 现在的规则 |
|---|---|
| 验证码发送冷却 | 同一手机号，60 秒只能申请一次 |
| 验证码发送配额 | 同一手机号，每个自然小时最多 5 次，每个自然日最多 10 次 |
| 验证码猜错限制 | 15 分钟内错 5 次，锁定 15 分钟 |
| 重发验证码 | 不能清除之前的猜错次数 |
| 验证码一次性使用 | 正确登录使用后，立即删除，不能再次使用 |
| IP 防刷 | 同一 IP，每分钟最多请求发送接口 20 次、登录接口 60 次 |
| 秒杀限流 | 每券每秒 100 次；每用户每 10 秒 5 次；同用户抢同券必须间隔满 2 秒 |
| 退出登录 | 删除 Redis Token，之后旧 Token 访问受保护接口返回 401 |
| 异常处理 | 太频繁返回 429；保护系统不可用返回 503 |
